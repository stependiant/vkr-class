Объектом разработки является платформа онлайн-бронирования услуг Easyappoint, предназначенная для организации записи клиентов к частному мастеру.

Целью выпускной квалификационной работы является разработка программной платформы, автоматизирующей настройку рабочей доступности мастера, подключение клиентов по приглашению, расчет доступных временных интервалов, создание бронирований и отправку уведомлений о событиях записи.

В процессе разработки были выделены основные сущности предметной области: пользователь, мастер, клиент, пригласительная ссылка, рабочая доступность, бронирование, внешнее календарное событие и событие уведомления. Спроектированы серверная и клиентская части, база данных, интеграция с Google Calendar, событийный обмен через Kafka и сервис Telegram-уведомлений.

Серверная часть реализована на языке Kotlin с использованием Ktor, клиентская часть -- на React и TypeScript. Для хранения данных используется PostgreSQL, для миграций -- Flyway, для публикации событий -- Kafka.

Разработанная платформа может использоваться частными специалистами для централизованного ведения расписания, снижения количества ручных операций и предотвращения конфликтов при записи клиентов.

List of keywords: online booking, appointment scheduling, master, client, web application, microservice architecture, Kotlin, Ktor, React, TypeScript, PostgreSQL, Kafka, Google Calendar, Telegram, notifications, database, availability, booking, invite link.

The object of the development is Easyappoint, an online booking platform for arranging appointments between an individual master and clients.

The purpose of the final qualification work is to develop a software platform that automates master availability management, client onboarding by invite link, available slot calculation, booking creation and notification delivery for appointment events.

During the development process, the main domain entities were identified: user, master, client, invite link, working availability, booking, external calendar event and notification event. The server-side and client-side parts, the database, Google Calendar integration, Kafka-based event exchange and the Telegram notification service were designed.

The server side is implemented in Kotlin using Ktor, while the client side is implemented with React and TypeScript. PostgreSQL is used for data storage, Flyway is used for database migrations, and Kafka is used for event publishing.

The developed platform can be used by individual specialists to manage appointment schedules centrally, reduce manual operations and prevent booking conflicts.
